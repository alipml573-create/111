日常演示请双击根目录的 `启动答辩.command`，打开 `http://127.0.0.1:4173/`。服务后台运行，可关闭启动终端；重复启动复用本项目服务，重启电脑后再次双击。该脚本直接提供已构建的 `dist`，不需要联网安装依赖，日志位于根目录 `.runtime/server.log`。

开发时在本目录运行：

```sh
pnpm run dev
pnpm run verify
pnpm run build
```

修改源码后须重新运行 `pnpm run build`，4173才会展示新版本。开发服务使用5173，支持热更新。正式文件采用相对资源路径，可迁移至静态服务器；不要以file协议直接打开 `dist/index.html`。

## 库职责

| 工具 | 实际任务 |
| --- | --- |
| Reveal.js 6 | 导航、键盘控制、URL定位、原生总览、独立演讲者视图 |
| React + TypeScript | 分页组件、状态同步与类型检查 |
| Magic UI BlurFade + Motion | 克制的标题入场；第八页主图初始可见以避免一秒切换时空框，支持减少动态效果 |
| Magic UI NumberTicker | 少量关键数字入场，不用于榜单名次等字符串 |
| Radix Dialog | 原比例大图、帮助、页内讲稿、文字编辑；管理焦点与Esc |
| Moveable + Selecto | 编辑模式选择、拖动、图片等比例调整 |
| Tiptap | 关键文本修改，保存后保持页面既有字体和排版 |
| Zustand | 编辑变更、撤销、重做及保存状态 |
| Dexie / IndexedDB | 当前浏览器本机保存与刷新恢复 |
| Lucide | 演示与编辑操作图标 |
| Vite | 本地开发与生产构建 |

原准备的依赖、Magic UI来源记录及许可保留。OGL等工具没有必要任务，因此没有引入粒子、光斑或复杂3D。直接使用Reveal实例，不再套一层框架；编辑模块按需加载。

## 素材维护

原始素材完整保留。根目录 `scripts/prepare-assets.mjs` 生成最大1600px的WebP和640px缩略图，保持比例并处理EXIF方向；它需要脚本指定的本机Sharp运行库。`scripts/inspect-assets.py` 生成清单及接触表。根目录运行 `node scripts/check-assets.mjs` 检查131项前景素材映射（原118项、封面抠像、第三页新增3项、第四页新增8项、第五页新增1项）、262个衍生资源与页面引用。

`scripts/prepare-ambient-backgrounds.mjs` 将五张附件原图完整归档为 `public/assets/ambient-v5/reference-01.png` 至 `05.png`，只转换格式为同尺寸WebP，不裁切、重绘或改变内容。日常构建不必重复运行。`node scripts/check-ambient-backgrounds.mjs` 检查原图SHA-256、尺寸、五个背景资源及15页映射。五张运行时背景合计约243KiB。

前景检查现在报告126项页面引用及五个精确撤下素材：两个学院Logo、第九页《浮生一日》证书、第十二页工作室Logo与学院账号截图，其余未引用素材仍报错；131项映射、262个衍生文件及118份原素材继续检查。第三页邮件原图、原Logo、正文裁切、透明PNG及无损WebP在 `public/assets/interview-v1/`，来源哈希与裁切坐标在 `素材核对/第三页面试邀请/asset-inventory.json`。处理脚本为 `scripts/prepare-interview-assets.mjs`；已归档输出，日常构建不需要生成或处理图片。

第四页八张透明PNG与WebP在 `public/assets/brand-v1/`，原文件仍在原素材目录。`scripts/prepare-brand-assets.mjs` 复用两张原Alpha，并将六份图像生成蒙版与原RGB合成，裁掉透明留白；无重绘品牌或产品标签。`node scripts/check-brand-assets.mjs` 检查原图SHA-256、映射、真实Alpha及透明PNG可见像素与原RGB逐像素一致性。提示词与来源在 `素材核对/第四页品牌与内容/`，日常构建不需要重复生图。

第五页Logo在 `public/assets/netjoy-v1/`，`scripts/prepare-netjoy-assets.mjs` 仅裁掉原透明PNG的空白边缘，复用原RGB及Alpha，无图像生成调用。`node scripts/check-netjoy-assets.mjs` 检查原图哈希、资源映射、真实透明Alpha，以及裁切PNG与原图对应区域的RGBA逐像素一致性。四张作品/榜单/样片继续使用原映射；素材与电脑端验收记录在 `素材核对/第五页云想科技/`。

## 边界

- 网页可在本地运行，也可通过仓库的 `gh-pages` 静态分支发布至 GitHub Pages；站点不含统计或第三方字体请求。第三页Logo与第四页六张素材的背景提取使用图像生成工具，最后仅采用其Alpha蒙版并保留原RGB；邀请邮件没有提交至外部设计或图像服务。
- 素材只有图片，没有视频文件；片库展示真实封面/样片墙，不伪造播放功能，完整作品使用提供的飞书链接。
- 未提供二维码图片，以真实作品集链接代替，不使用示意二维码。
- 本地编辑是微调工具，不是页面构建器。只有可选框的关键文本/图片支持直接编辑；数字和固定标签在源码维护。
- 保存属于浏览器、域名及端口的本机存储。5173与4173不共享，需导出/导入JSON备份。
- 默认ID对应的同一素材在不同页复用时，替换可能同步；显式ID的独立位置不受影响。图片不拉伸。
- JSON备份含替换图片数据，请私下保存。导入替换编辑状态，可立即撤销。
- 独立演讲者视图依赖弹窗，内嵌预览无法保证。页内讲稿可直接查看，但会出现在投影上。
- 经历、数字、奖项仍需答辩人确认；全屏、双屏投影和外链权限仍需在现场设备预演。
